🛡 Safe Execution

Action Lifecycle — Propose → Validate → Approve → Execute

Every agent action follows a strictly typed 4-state machine. No shortcuts, no exceptions.

Structured Action Proposal Schema

{
  "agent": "inventory",
  "summary": "RUN-SHOE-BLK-42 reorder required",
  "confidence": 0.96,
  "risk_level": "medium",
  "evidence": [
    { "type":"metric", "claim":"1.5 days cover" },
    { "type":"policy", "ref":"MIN_COVER_7_DAYS" }
  ],
  "proposed_actions": [{
    "action_type": "purchase_order.create",
    "parameters": { "qty": 440, "total_minor": 1848000 },
    "idempotency_key": "tenant:sku:po:440:2026",
    "requires_approval": true,
    "autonomy_level": "L2"
  }]
}
1
PROPOSED — Agent outputs JSON contract with evidence citations
2
POLICY CHECK — Deterministic rules: autonomy level, risk score, monetary ceiling
3
PENDING APPROVAL — High-impact actions require authorized human sign-off with 24h TTL
4
EXECUTED & AUDITED — Idempotent connector call, external ref logged, rollback data stored

L1 Auto-execute • L2 Human approval required • L3 Exec sign-off • L4 Board approval

⚙️ Resilience

Failure Modes, Fallbacks & Circuit Breakers

Handling upstream outages, rate limits, model degradation, and data consistency failures

Outage

LLM / Gemini Unavailable

Circuit breaker opens immediately. Platform falls back to deterministic rules or queues events for manual operator handling. No data loss.

Rate Limit

Carrier / Commerce 429

Exponential backoff with jitter. Worker queue throttling and DLQ replay alarms. Operators notified via CloudWatch alarm.

Model Drift

Hallucinated Citation

Deterministic citation verifier rejects any reply claiming unverified tracking dates or unauthorized refund amounts — proposal blocked.

Concurrency

Dual Approval Race

409 Conflict returned to second approver. Database-level optimistic locking prevents double-execution of high-value actions.

Edge Case

Stale Action Expiry

24h TTL on proposals. Actions older than 24h auto-expire. Agents re-evaluate fresh data rather than executing stale recommendations.
